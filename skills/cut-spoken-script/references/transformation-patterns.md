# 口播转换示例库

只在需要把形容词、行业术语或抽象宣传语改成可证明表达时读取本文件。示例数字只说明转换方式，不得当成新任务的事实使用。

## 形容词改成动作与证据

| 空泛表达 | 改写方向 | 示例 |
| --- | --- | --- |
| 工作很累 | 给出持续时间和实际动作 | 连续一周从早上 7 点干到晚上 11 点，上厕所时还在帮用户想重点。 |
| 瘦身效果特别好 | 给出周期和前后变化 | 三个月，腰围从二尺八变成二尺四，原来的裤子要换。 |
| 服务很贴心 | 给出发生条件和服务动作 | 下雨后，我们会把客户送到地库。 |
| 使用很方便 | 对比使用前后的步骤 | 原来要分别申请三个接口、写三套代码；现在提一个问题，系统自己找数据。 |
| 能力很强大 | 给出一次真实任务与交付物 | 一次运行拉回两期财报、估值和分析师预测，并生成对比结果。 |
| 速度很快 | 给出同口径耗时 | 把原来需要两小时的步骤压到十分钟；必须说明测试条件。 |
| 覆盖全球 | 列出具体市场或覆盖口径 | 支持 A 股、港股和美股；更多市场按可核实清单列出。 |
| 免费使用 | 说清免费对象和限制 | 搜索免费；拉取数据按额度扣费，新用户额度以当期规则为准。 |

转换顺序：先找真实证据，再选择动作、数字、场景、对比或演示。找不到证据时删除，不要凭经验补数字。

## 行业语言改成用户语言

| 行业表达 | 用户表达 |
| --- | --- |
| 面部松弛、胶原蛋白流失 | 我的脸垮了，看起来没精神。 |
| 体态矫正、核心激活 | 我穿什么衣服都不好看，站着也没精神。 |
| 多源数据聚合 | AI 自己去不同接口找财报、行情和新闻。 |
| 智能路由 | 它先比较哪些接口能用、要多久、花多少，再选择一个调用。 |
| 全链路自动化 | 你给出问题，它自己找资料、执行步骤，最后交付结果。 |
| 一站式解决方案 | 原来要打开几个工具、做几步；现在在哪一步完成。 |

保留专业名词的必要条件：用户必须认识它才能完成操作、理解风险或核对结果。保留后立刻补一句它对用户意味着什么。

## 三个快速测试

### 品牌替换测试

把产品名替换成任意竞品。如果整段仍然成立，说明文案缺少独特动作、结果或边界。

### 镜头证明测试

追问“剪辑师能用什么画面证明这句话？”如果只能配装饰性素材，优先改成可录屏、可对比、可截图或可复核的表达。

### 删除影响测试

追问“删掉这句话，观众会少知道什么？”如果不会少知道事实、判断、动作或风险，删除。

## 防止过度删除

以下内容即使不刺激，也可能必须保留：

- 结论成立所需的前提和时间口径。
- 金融、医疗、法律等领域的风险与适用边界。
- 引用、数据来源和实测条件。
- 从问题到结论之间不可缺少的因果桥梁。
- 用户明确要求保留的品牌信息和行动步骤。

删稿的目标是提高单位时间的信息和可信度，不是把所有解释都改成口号。
